# Brochure scans

The source photographs for `../BROCHURE-TRANSCRIPTION.md` belong here, so that every published
fee, duration and entry requirement can be traced back to the document it came from.

Save the nine brochure photographs into this folder as `panel-01.jpg` … `panel-09.jpg`, in the
order they appear in the transcription. If Motech has the original brochure artwork (PDF or
InDesign), that is better than photographs — add it as `brochure.pdf`.

These are reference scans for the repository, not website imagery. They are photographs of a
folded printed page, with glare and page curvature, and are not fit to publish. Site photography
needs the original digital files from the institute.
