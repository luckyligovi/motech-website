# Images

Photographs belong here, and are wired up in `src/data/media.js`.

## Only photographs Motech owns

Use photographs taken at Motech, which the institute owns and may publish. Do not use stock
photography of other institutions: visitors read a photo on an institute's website as being
that institute, so stock imagery of another campus is a misleading claim about facilities.

Anyone recognisable in a photograph must have agreed to its use on a public website. Under
the Data Protection Act, 2019 that consent should be recorded, and for a student under 18 it
comes from a parent or guardian.

## Naming

Describe the subject in the filename, because search engines read it:

- `motech-classroom-nairobi.jpg`
- `motech-reception-tom-mboya-street.jpg`
- `motech-food-and-beverage-practical.jpg`

Not `IMG_4821.jpg` or `hero-bg-2.jpg`.

## Size

Export at roughly 2000px wide for full-width images and 1200px for cards, as JPEG at about
75% quality or WebP. Keep each file under about 400KB: many visitors are on mobile data.

Record the real pixel dimensions in `src/data/media.js` so the layout does not shift as
images load.
